# Examples

> -> Kendi çalışmalarımı yaptığım bir adet Javascript çalışma ortamım.
> -> Daha çok öğrenme amaçlı olarak bunları yazmaktayım.
> -> npm paketleri kurulu ve tailwind ile CSS konfigürasyonlarımı yapıyorum.
> -> paket olarka sadece npm kurulumu yapılması yeticektir çalıştırılması için.
> -> Local tarafta tailwind çalışması için gereken kod : 
>> -> npx @tailwindcss/cli -i ./src/input.css -o ./dist/output.css --watch
